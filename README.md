## 📂 Cấu trúc
```
3diot-c-thuc-chien/
├── chapters/        # 12 chương — code mẫu, bài tập, lời giải
├── common/          # thư viện dùng chung (helper, header)
├── projects/        # mini project & final project
├── docs/            # tài liệu: workflow, coding style, setup
└── scripts/         # script tiện ích
```

- GNU Make
- Git

```bash
cd chapters/01-introduction/examples/hello-world
make run
```
